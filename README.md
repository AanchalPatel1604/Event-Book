# 🎟️ EventBook - Event Booking System

EventBook is a full-stack event booking web application that allows users to discover events, select seats, and book tickets online.

## 🚀 Features

- 🎉 Browse upcoming events
- 🔍 Search events
- 📅 View event details
- 💺 Select seats
- 🎟️ Book tickets
- 👤 User login
- 📋 View My Bookings
- 🗄️ MongoDB database
- ⚡ REST API
- 💻 React frontend

## 🛠️ Technologies Used

### Frontend
- React.js
- React Router
- Axios
- CSS
- Vite

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
